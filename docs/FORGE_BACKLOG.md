## 14. VERSION更新・commit・main／gh-pages配信

**すべてのゲートを満たすまで実行しない。**

1. `pwa/sw.js` の `VERSION` を1つだけ上げる（現在 `forge-v32`）
2. `npm run build:all`
3. `npm run verify`
4. `git diff` 確認 → commit
5. `git push origin main`
6. `git push origin $(git commit-tree main:pwa-dist -p origin/gh-pages -m "deploy: forge-vN"):gh-pages`
7. 公開URLで新 VERSION を確認

⚠️ **main だけ push しても配信物は変わらない。push は2本。**

状態: ⬜
