iPhone で使えるようにする手順

このフォルダの中身を無料のWebサーバーに置くだけで使えます。プログラミングの知識は不要で、 ファイルをドラッグ＆ドロップするだけです。いちばん簡単な GitHub Pages（無料）で説明します。

手順1 — PCでの公開作業（最初の1回だけ・5〜10分）

  1. github.com で無料アカウントを作る（お持ちなら不要）
  2. 右上の + → New repository
    Repository name は train800（名前は何でもOK）／ Public を選択 → Create repository
  3. 作成後の画面にある uploading an existing file をクリックし、 このフォルダの中身を全部ドラッグ＆ドロップ → Commit changes を押す
    index.htmlbundle.jsstyles.csssw.js manifest.webmanifesticon-180.pngicon-192.pngicon-512.png
  4. リポジトリの Settings → 左メニューの Pages → Branch を main / (root) にして Save
  5. 1〜2分待つとURLが表示されます
    例）https://あなたのID.github.io/train800/

手順2 — iPhoneでの設定

  1. 上のURLを Safari で開く
  2. 画面下の共有ボタン（□に↑）→ 「ホーム画面に追加」
  3. ホーム画面のアイコンから起動する
    以後はアプリと同じ感覚で使えます。一度開けばオフラインでも動作します。

使い始めの順番

  • プロフィール — PB（1:49.51 / 49.0 / 3:56）と暑熱耐性 low を入力
  • 目標・レース — 目標 1:48.90 と本命レースの日程・ラウンド構成を入力
  • 記録 — 「有酸素の実測データ」にペース走を1本入力（例: 8km / 30:40 / 平均HR 186）。 これを入れるまで有酸素の設定は「推定値」のままです
  • 目標・レース — 「プランを自動生成」を押す
  • カレンダー — チーム練習など動かせない日を「固定セッション」で登録

毎日の運用は、朝に安静時HR・睡眠・張り・疲労を記録（30秒）、練習後にRPE・達成度・ラップを記録（1分）。 これだけでCFEが更新され、以降のメニューのペースが自動で組み変わります。

データの保管について

データはあなたのiPhoneの中だけに保存されます（外部への送信は一切ありません）。 その代わり、機種変更やSafariのデータ消去で消えます。 アプリ内の「データ管理」→「バックアップをダウンロード」を定期的に実行してください。 同じ画面からバックアップの復元もできます。
