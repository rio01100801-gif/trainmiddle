 800M TRAINING (PWA版) を iPhone で使えるようにする手順
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

 ※ このファイルが文字化けする場合は、同じフォルダの
    setup-guide.html をブラウザで開いてください。

このフォルダの中身を無料のWebサーバーに置くだけで使えます。
いちばん簡単なのは GitHub Pages です (無料・アカウント作成のみ)。


【手順1】PCでの公開作業 (最初の1回だけ・5〜10分)

 1. https://github.com で無料アカウントを作る (持っていれば不要)

 2. 右上の「+」→「New repository」
      Repository name : train800  (名前は何でもOK)
      Public を選択 → 「Create repository」

 3. 作成後の画面にある「uploading an existing file」をクリック
      このフォルダの中身を全部ドラッグ&ドロップする
        index.html
        bundle.js
        styles.css
        sw.js
        manifest.webmanifest
        icon-180.png / icon-192.png / icon-512.png
      → 「Commit changes」を押す

 4. リポジトリの「Settings」→ 左メニューの「Pages」
      Branch: main / (root) を選んで「Save」

 5. 1〜2分待つとURLが表示される
      例)  https://あなたのID.github.io/train800/


【手順2】iPhoneでの設定

 1. 上のURLを Safari で開く
 2. 画面下の共有ボタン (□に↑) → 「ホーム画面に追加」
 3. ホーム画面のアイコンから起動する
      以後はアプリと同じ感覚で使えます。
      一度開けばオフラインでも動作します。


【手順3】新しい版が届いたときの更新のしかた

 作り直しではありません。同じリポジトリのファイルを上書きするだけです。
 URLは変わらず、これまでに入力した練習データも消えません。
 (データはGitHubではなくiPhoneの中に入っているため)

 ■ PCの場合
   1. GitHubのリポジトリを開く → 「Add file」→「Upload files」
   2. 新しいフォルダの中身を全部ドラッグ&ドロップ (同名ファイルは上書きされる)
   3. 「Commit changes」を押す
   4. 1〜2分待つ → iPhoneでアプリを開き直す (2回開くと確実)

 ■ iPhoneだけで完結させる場合
   1. 受け取ったzipを「ファイル」アプリに保存する
   2. zipを長押し → 「展開」 (フォルダができる)
   3. Safariで github.com を開き、リポジトリ →「Add file」→「Upload files」
      ※ 画面が狭くて操作しづらい場合は、Safariの「あ」ボタン→
        「デスクトップ用Webサイトを表示」にすると押しやすくなります
   4. 「choose your files」→ 展開したフォルダの中身を全部選ぶ
   5. 「Commit changes」を押す
   6. 1〜2分待つ → ホーム画面のアイコンから開き直す

 更新が反映されないときは、アプリを一度終了してから開き直してください。
 (アプリ本体は起動のたびに最新を取りに行く作りになっています)


【使い始めの順番】

 1. プロフィール      PB (1:49.51 / 49.0 / 3:56) と暑熱耐性 low を入力
 2. 目標・レース      目標 1:48.90 と本命レースの日程・ラウンド構成
 3. 記録              「有酸素の実測データ」にペース走を1本入力
                       (例: 8km / 30:40 / 平均HR 186)
 4. 目標・レース      「プランを自動生成」を押す
 5. カレンダー        チーム練習など動かせない日を「固定セッション」で登録

 毎日: 朝に安静時HRなどを記録 → 練習後にRPE・達成度・ラップを記録


【重要】データの保管について

 ・データはあなたのiPhoneの中だけに保存されます (外部送信はありません)
 ・機種変更や Safari のデータ消去に備えて、アプリ内の
     「データ管理」→「バックアップをダウンロード」
   を定期的に実行してください
